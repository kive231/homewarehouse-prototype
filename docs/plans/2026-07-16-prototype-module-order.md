# 家庭仓库原型模块顺序

## 总体顺序

1. 一级页面
2. 物品闭环
3. 空间与分类
4. 扫码与库存流水
5. 设置中心
6. 二维码标签

## 页面划分

| 模块 | 顺序 | 页面 |
| --- | --- | --- |
| 一级页面 | 01–06 | 首页、物品、空间分类、扫码、库存流水、我的 |
| A · 物品 | A01–A07 | 物品详情、新增、编辑、消耗、补货、移动、归档删除 |
| B · 空间分类 | B01–B08 | 空间下钻、盒子详情、空间新增/编辑、分类下钻、细类详情、分类新增/编辑 |
| C · 扫码流水 | C01–C04 | 物品识别、位置识别、无法识别、流水详情 |
| D · 设置 | D01–D04 | 家庭与成员、提醒、数据与导出、关于与帮助 |
| E · 二维码 | E01–E04 | 二维码管理、生成标签、图片已保存、打印标签 |

## 画布规则

- 同一模块横向排列，模块之间纵向递进。
- 页面名称使用模块编号，新增页面插入对应模块末尾。
- 一级页面固定在首行，模块总览固定在第二行。
- 公共组件保留在画布顶部，不混入业务页面顺序。
