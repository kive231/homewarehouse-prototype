# 家庭仓库原型模块顺序

## 总体顺序

1. 一级页面
2. 前置与发现
3. 物品闭环
4. 空间与分类
5. 扫码与库存流水
6. 设置中心
7. 二维码标签

## 页面划分

| 模块 | 顺序 | 页面 |
| --- | --- | --- |
| 一级页面 | 01–05 | 首页、物品、空间分类、扫码、我的 |
| P · 前置发现 | P01–P05 | 登录、首次建仓、搜索结果、快捷操作选物、待处理列表 |
| A · 物品 | A01–A09 | 物品详情、新增、编辑、消耗、库存不足、补货、移动、归档删除、彻底删除确认 |
| B · 空间分类 | B01–B10 | 空间下钻、盒子详情、空间新增/编辑、分类下钻、细类详情、分类新增/编辑、空间内容迁移、分类物品迁移 |
| C · 扫码流水 | C01–C05 | 物品识别、位置识别、无法识别、库存流水、流水详情 |
| D · 设置 | D01–D04 | 家庭与成员、提醒、数据与导出、关于与帮助 |
| E · 二维码 | E01–E09 | 二维码管理、生成标签、图片已保存、打印标签、资产详情、选择绑定对象、已停用资产、选择打印机、权限与异常 |

## 画布规则

- 同一模块横向排列，模块之间纵向递进。
- 页面名称使用模块编号，新增页面插入对应模块末尾。
- 一级页面固定在首行，模块总览固定在第二行。
- 公共组件保留在画布顶部，不混入业务页面顺序。
- 当前共 47 个手机页面、1 个公共顶部栏组件和 1 个模块总览。
