# 家庭仓库业务与原型修复计划

## 一句话目标

按业务依赖顺序统一领域规则、导航、库存、空间分类、二维码和异常状态，并让 Pencil 原型与业务文档保持一致。

## 全局约束

- 只做手机端，画板保持 `320 × 682`。
- 保留现有 Lavender Cream 视觉体系和 5 个底部入口。
- 详情与操作页面不新增底部一级导航。
- 库存数量只能通过补货、消耗和移动业务动作改变。
- 低库存统一为 `当前库存 <= 物品阈值`。
- 二维码绑定对象统一为物品或任意空间节点；同一二维码只能绑定一个对象。
- 不引入采购审批、供应商、财务或企业多仓。

## 执行任务

### [x] 1. 统一领域语言、导航和接口边界

- 输入：现有业务框架、33 个移动页面和审查结论。
- 产物：家庭、成员、库存批次、二维码生命周期与统一术语。
- 验证：检索文档中“个人账户”“4 Tab”“只绑定盒子”等旧规则。
- 预期：文档只保留一套可实现规则。

### [x] 2. 修复库存逻辑和物品操作原型

- 输入：物品详情、编辑、消耗、补货和删除确认页面。
- 产物：阈值边界正确、库存只读、补货批次/保质期、删除输入确认。
- 验证：逐页读取文本并运行 Pencil 布局检查。
- 预期：所有库存变化都能生成流水，不存在直接改数量入口。

### [x] 3. 补齐导航、搜索、首次建仓和快捷操作闭环

- 输入：首页、物品、扫码、空间、我的五个一级入口。
- 产物：登录、首次建仓、搜索结果、快捷操作选择、待处理列表。
- 验证：每个一级入口和首页快捷动作都有明确承接页面。
- 预期：新用户和高频操作不再出现流程断点。

### [x] 4. 补齐空间分类迁移和多层 CRUD

- 输入：空间/分类下钻页及编辑页迁移入口。
- 产物：柜子/层/盒子通用表单规则、分类 1–3 级规则、关联对象迁移页。
- 验证：删除受阻后能完成迁移并返回删除确认。
- 预期：层级维护形成完整增删改查闭环。

### [x] 5. 补齐二维码生命周期与打印异常状态

- 输入：二维码管理、生成、保存和打印页面。
- 产物：对象选择、解绑/停用/启用、打印机选择与异常、权限拒绝状态。
- 验证：物品与空间均可完成生成、绑定、保存和打印。
- 预期：二维码状态和编号语义唯一、可追溯。

### [x] 6. 全局移动端可用性修复

- 输入：全部页面文本、触摸区和色板。
- 产物：移除遗留纯蓝色、提高小字号对比度、扩大关键触摸区。
- 验证：全局颜色、字体、触摸区、未知图标和布局扫描。
- 预期：无非预期蓝色、无小于 44px 的关键操作、无新增溢出。

### [x] 7. 文档同步、全局验收与提交

- 输入：最终 Pencil 页面和业务文档。
- 产物：最新页面数、模块顺序、跳转清单、校验结果。
- 验证：`git diff --check`、Pencil 全局布局检查和关键词扫描。
- 预期：文档与原型一致，Git 提交可回溯。

## 回滚方式

- 文档使用对应 Git 提交反向提交。
- Pencil 每个新增页面独立存在；单阶段失败时删除该阶段新增根页面，不重置其他页面。

## 最终验收标准

- 领域规则、导航、术语和页面状态不存在相互矛盾。
- 登录、建仓、搜索、快捷操作、层级迁移和二维码管理均有原型承接。
- 库存批次、保质期、低库存阈值和流水规则一致。
- 全部页面通过布局、图标、颜色和关键触摸区校验。

## 执行结果

- 原型共 47 个手机页面，覆盖 5 个一级页、前置发现、物品、空间分类、扫码流水、设置和二维码 7 个模块。
- 新增登录、首次建仓、搜索、快捷操作、待处理、迁移、库存不足、彻底删除、二维码生命周期和硬件异常状态。
- 低库存统一为 `当前库存 <= 物品阈值`；编辑页库存只读；补货记录库存批次。
- 11 组底部胶囊导航已统一，扫码图标为 28px，标签在图标下方居中。
- 移除遗留纯蓝色；101 处语义色文本和 24 个主按钮完成对比度修复。
- 47 页布局校验完成：40 页无问题，7 页仅有预期的流体丝带裁切；未知图标和批注入口均为 0。
