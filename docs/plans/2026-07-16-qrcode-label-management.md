# 二维码标签与管理页面设计

## 页面闭环

`我的 → 二维码管理 → 生成二维码标签 → 保存图片 / 连接打印机`

## 已完成页面

- 二维码管理：统一管理物品码、任意空间节点码和未绑定码，展示二维码编号、业务编号与状态。
- 生成二维码标签：选择已有物品或空间节点，预览标签并调整尺寸、打印机。
- 图片已保存：显示保存结果、文件名，并提供分享、继续打印入口。
- 打印二维码：显示已连接打印机、打印份数、标签纸与打印浓度。
- 二维码资产详情：查看绑定对象、历史记录，并支持重新生成、解绑和停用。
- 选择绑定对象：可绑定物品或柜子、层、收纳盒等任意空间节点。
- 已停用资产：展示停用状态，并支持重新启用和重新绑定。
- 选择打印机：发现附近设备、手动添加、查看连接帮助。
- 权限与异常：覆盖相册权限、蓝牙权限、打印机断开和标签纸不足。

## 统一规范

- 手机画板统一为 `320 × 682`。
- 复用详情页顶部栏，不增加页面批注入口。
- 使用 Funnel Sans / Inter / Geist 与 Lavender Cream 配色。
- 保存图片和打印为两条独立结果路径，避免在同一按钮内混合动作。
- 二维码资产支持绑定、解绑、停用和重新启用；同一时刻只能绑定一个对象。
- 相册、蓝牙、打印机断开和缺纸必须提供异常状态。
